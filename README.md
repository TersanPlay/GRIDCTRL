# GRIDCTRL

Landing page e Skill especializada em UI/UX e Frontend.

Projeto com identidade visual Swiss Grid / Tech Minimalism, baseada em referências visuais de design e no mockup original da Skill.

## Acessar a landing page

Abra `index.html` em um navegador ou configure GitHub Pages para servir a raiz do repositório.

## Skill

Veja [`skill/SKILL.md`](skill/SKILL.md) para as instruções operacionais e o design system.

## Tecnologia

HTML, CSS e JavaScript incorporados em um único arquivo para facilitar hospedagem estática. Sem dependências de build.
