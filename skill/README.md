# GRIDCTRL Skill

Skill specialized in UI/UX + Frontend engineering, with its visual identity defined by the approved GRIDCTRL landing-page mockup.

- `SKILL.md`: main instructions for agents compatible with SKILL.md.
- `references/skill-mockup-spec.md`: detailed visual specification.
- `assets/tokens.json` and `assets/tokens.css`: design tokens.
- `assets/robot-reference.webp`: reference art from the landing page hero.

For the interactive website, see [../index.html](../index.html).

## Design principles
Technical Swiss grid, visible linework, modular components, muted grayscale and small orange accents. Preserve functional accessibility while matching the visual language. No framework requirement; adapt to the target project's existing stack.
