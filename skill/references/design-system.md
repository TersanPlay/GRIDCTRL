# GRIDCTRL Design System

## Visual identity
Technical Swiss-grid, light neo-brutalism, restrained retro-futurism. Default background #ECECEC, off-white cards #F7F7F7 and #FDFDFD, graphite #101010, dividers #C8C8C8, muted #626262 and vivid orange #FF741D. Do not overuse orange.

## Layout
Build from a centered outer frame with a dark outline and mild rounding. Add visible one-pixel orthogonal grid/divider lines. Use a consistent 8px rhythm, rectangular component surfaces and compact CTA buttons. The header is modular, hero uses left display typography and right visual/robot, and sections align to shared columns. On narrow screens, collapse modules deliberately rather than hiding content.

## Typography
Display: large geometric segmented/industrial type approximation. Body: neutral sans-serif. Microcopy, labels and indices: monospaced. Ensure legibility at zoom 200%, avoid letter-spacing that impairs reading, and never render meaningful copy as an image. Proprietary font is not included and must not be assumed.

## Components
Header, hero, technical counters, capability cards, workflow cards, use-case cards, FAQ accordion, insights cards, downloads, newsletter and large footer wordmark. Reuse shared spacing, lines, interactive states, typography scales and colors. Primary action orange, secondary outlined; inline arrows and small orange square markers.

## Motion and feedback
Small hover/focus/active transitions; respect prefers-reduced-motion. Modal and accordions keyboard accessible. Preserve stable layout with no heavy parallax or animation that obscures content.
