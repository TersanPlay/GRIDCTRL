# GRIDCTRL · React + shadcn/ui architecture

**Runnable integration** using the GRIDCTRL React ThemeProvider, its CSS export, and **local source components following the shadcn/ui copy-to-project model**. Button and Card are styled local components. Dialog, Accordion, Switch and Slot use official Radix primitives. These example components are **not claimed to be the files generated by the shadcn CLI**.

## Start
From repository root, run `npm run build`. In this example folder run:
```bash
npm install
npm run dev
```
Vite serves a fully working component showcase. Switch between 6 palettes and open the accessible Radix Dialog.

## Using official shadcn/ui
If you want files generated by the official shadcn CLI, set up shadcn/ui in your actual React project, run `npx shadcn@latest add button card badge dialog accordion switch`, and replace the local examples with the generated UI components. **Preserve GRIDCTRL semantic tokens** and your existing component library conventions; do not blindly overwrite files. See <https://ui.shadcn.com/docs/installation> for the exact current setup.

## Contract
`GridctrlProvider` and `useGridctrl()` consume the shared registry. No random layout behavior; no browser-native unstyled controls; descriptive text and modal surfaces follow semantic colors.
