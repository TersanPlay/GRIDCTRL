# GRIDCTRL · Vue 3

This is a fully runnable Vue 3 + Vite example consuming `@tersanplay/gridctrl` directly, independent of React.

From repository root: `npm run build`

From this folder:
```bash
npm install
npm run dev
```

The preset selector persists its selection locally and switches the `data-gridctrl-variant` attribute without changing component position or navigation. The app uses native semantic HTML **styled through GRIDCTRL**, not unstyled browser defaults. For extensive Vue component libraries, reuse existing accessible components rather than migrating the app to React.
